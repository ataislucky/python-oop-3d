Kubah Brankas Data: Private Attribute & @property

Atribut privat self.__saldo dikunci di dalam perisai enkapsulasi dan hanya boleh diakses melalui gerbang validasi @property.

🛡️
Brankas Terkunci (Saldo Saat Ini: Rp 1.000.000)

Pilih salah satu skenario demo di bagian bawah untuk menguji perlindungan enkapsulasi.

rekening_bank.py
Encapsulation 
class RekeningBank:
    def __init__(self, pemilik, saldo_awal):
        self.pemilik = pemilik
        # Private attribute (dilindungi name mangling)
        self.__saldo = saldo_awal

    @property
    def saldo(self):
        """Gerbang Getter: Membaca data dengan aman"""
        return self.__saldo

    @saldo.setter
    def saldo(self, nilai):
        """Gerbang Setter: Validasi sebelum ubah inti"""
        if nilai < 0:
            raise ValueError("Saldo tidak boleh negatif!")
        self.__saldo = nilai

# --- Kode Pemanggil (Client) ---
akun = RekeningBank("Budi", 1000000)
