PILAR 01 • ABSTRACTION from abc import ABC

Abstraksi (Black-Box & X-Ray)

Visualisasi kontras antara kesederhanaan antarmuka publik (@abstractmethod) dengan kerumitan implementasi internal di balik layar, termasuk fitur hot-swap backend tanpa mengubah kode pemanggil.

class Messenger(ABC):
  @abstractmethod
  def send(self, pesan): ...
Fitur: Mode X-Ray, Hot-Swap Engine Buka Simulasi 3D ↗
PILAR 02 • ENCAPSULATION @property & __private

Enkapsulasi (Kubah Brankas Data)

Simulasi perisai pelindung atribut privat (self.__saldo), mekanisme Name Mangling, penolakan akses ilegal, serta gerbang validasi @property dan @setter.

@saldo.setter
def saldo(self, nilai):
  if nilai < 0: raise ValueError
Fitur: Uji Serangan Akses, Setter Gate Buka Simulasi 3D ↗
PILAR 03 • INHERITANCE super().__init__() & MRO

Pewarisan (Hierarki Kelas & MRO)

Eksplorasi aliran atribut dari kelas induk (Kendaraan) ke kelas turunan (Mobil & Motor), inisialisasi super(), Method Overriding, dan pelacakan MRO.

class Mobil(Kendaraan):
  def __init__(self, merk, pintu):
    super().__init__(merk)
Fitur: Aliran Energi super(), MRO Tracer Buka Simulasi 3D ↗
PILAR 04 • POLYMORPHISM Overriding & Duck Typing

Polimorfisme (Dispatcher & Duck Typing)

Satu sinyal pemanggilan method identik (item.hitung_luas()) menghasilkan proyeksi geometri dan kalkulasi berbeda pada berbagai objek, termasuk dukungan Duck Typing tanpa pewarisan.

for bentuk in [Lingkaran(), Persegi(), Robot()]:
  print(bentuk.hitung_luas())
Fitur: Hologram 3D, Duck Typing Node Buka Simulasi 3D ↗
